# Aurelia

Aurelia is a personal diary app I'm building as a hobby project.

The goal isn't to create the next big productivity platform. I simply want to build a place where people can write down their thoughts, keep memories, and reflect on their lives in a calm and comfortable environment.

Along the way, this project is also a way for me to learn more about mobile development, application architecture, synchronization, and building software that lasts.

## Why?

Most diary apps either feel overly complicated, subscription-heavy, or focused on productivity rather than reflection.

Aurelia is my attempt at creating something simpler.

A place for:

- Thoughts
- Memories
- Daily reflections
- Personal growth
- Moments worth remembering

## Technical Goals

One of the main goals of this project is to explore sharing application logic between platforms while still keeping the user experience native.

The project aims to have:

### Shared

- Business Logic
- Data Models
- Networking
- Database Logic
- Synchronization Logic
- Authentication Logic

### Android

- Kotlin
- Jetpack Compose

### iPhone

- SwiftUI

This means Android and iPhone users will get interfaces designed specifically for their platforms while both applications use the same core functionality underneath.

```text
Shared Core
├── Business Logic
├── Data Models
├── Networking
├── Database Logic
└── Sync

Android App
└── Jetpack Compose

iPhone App
└── SwiftUI
```
